# WESA Completion Assessment

## Overall assessment

WESA has done a nice job in moving closer toward their own goal: providing tech personal users and small businesses with super easy checks of their Windows security settings. The evidence does support, however, a working example with limited scope of an audit. It's not yet enough to suggest that each and every test is correct amongst numerous Windows installations or that the tool supplies .

## What the demonstration supports

The four ‘check' items listed about in our review notes are: Windows Firewall, Microsoft Defender Antivirus, Defender Real-Time Protection and the Guest Account. The particular spot that was documented in the notes was the Guest Account set to be enabled—and then WESA stating FAIL. This lends credence to the idea that the test environment could be used to detect that insecure environment using the shown workflow.

Relevant interface, explanations of the risks, recommendations for remediation, and export of reports are appropriate for audience. They let the non-specialist user make associations between the configuration and what actions the users need to take. But it's not the same to describe these functions as it is to check each function individually.

## Evidence that remains limited

The review notes provided do not provide a full history of achievement or otherwise for each secure and insecure controlled. From these materials, it is therefore not possible to verify if all the four checks have been validated. Additional evidence would also be for the assessment of the behaviour when a query cannot be performed, there are not enough permissions or when a device is in a different security configuration.

In the written peer review response Martin later claims the team implemented 2 additional controls, and even packaged WESA as an executable. These changes are in answer to some suggestions that we have made regarding the coverage and deployment. We acknowledge them as announced improvements, but indicate that they aren't mentioned in the reply and lack any third party testing with the packaged version.

## How far the stated problem is solved

The project solves a crucial aspect of this issue: it will visualize selected configuration issues and inform the user how to fix these issues. It's a great benefit focused configuration audit. A PASS must be considered in the context of specified settings: it does not mean a device is free of malware or that it's protected from all threats.

In our opinion, WESA has shown part of the way it planned to solve the problem, and has stated that it continues to make more progress. A shorter test matrix, detailed test results/outputs as well as a clean-machine deployment test would make a stronger argument for completion. Whilst increasing the protection claims would warrant/will warrant a greater amount of evidence.
